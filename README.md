# Small Habits App

A small habit app. With a small frontend, backend, and a little bit of animations to make it look nice.

Live link is right here, if u want to check it out ---> https://habits-app-frontend.onrender.com

*This was hosted with render. Render has to boot up the server from scratch, so the webpage might feel slow*

# Technologies
  - Javascript
  - HTML
  - CSS/Tailwind
  - TypeScript
  - React
  - express (for backend) 

# What I learned
  - How to add different kind of animation with a module
  - Learned how to fetch reqeust from the backend with React.
  - Learned how to host an app on Render (for free)
