
Stuff that I am learning by doing fullstack:
    - When starting a fullstack project, the first step is to:
        - Make 2 folders, client (frontend), and a server (backend)

    Backend:
        - before making the whole backend, we have to install express.
        The first step:
            - npm init -y (to create the package.json file with default values)
            - npm install express (To install the express framework to help build the backend of this project)

        - To check if a request works in the backend you can execute that request in the terminal or with a tool.
        Terminal:
            (==> On Windows <==)
            Invoke-RestMethod -Uri "the route" `
            -Method "The Method"
            -Headers @{ "Content-Type" = "application/json" }
            -Body '{"key":"value"}'
        

Other info aside:
    - A package.json is a file that stores dependecies, scripts, and project info
    you would need a package.json file whenever you would need to use a npm package or node.js tools, like react, vue, etc.

    - it is important to remember that Node does not recreate the file on every request (backend)
    Everything insided "route.js" is loaded once.

    - to check what packages you have intalled so far you can do 'npm list --depth=0'.
    If you are trying to check for a specific package, you can just do 'npm list (cors/express/nodemon/etc...)'
